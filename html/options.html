Secure Profile Lock

Privacy

Clear browsing data when the profile locks
When the profile locks (on browser start or manual lock), the selected data is erased. A locked profile then contains no browsing traces — even if the extension is removed. This affects your own data on this profile; use with care.

Auto-lock

Lock automatically after inactivity
Lock the profile after a period with no keyboard or mouse activity, in addition to locking on browser start.
